# content

キャラクターと世界観のデータファイル。プロンプトテンプレートからキャラクター固有・世界観固有の文面を切り離すために置いている。

フロントは、選べるパッケージの一覧と表示用の文言を `GET /packages`（`src/packageCatalog/`）で受け取り、`packageId` を選んで各エンドポイントに渡すだけで、サーバー（`src/lib/packages.ts`）がここから世界観・キャラクター・生活様式を読み込み、プロンプトや今後の不在期間のシミュレーションに使う。

| フォルダ | 内容 |
|---|---|
| [`worlds/`](worlds/README.md) | 世界観（舞台の説明・ルール・生成してはいけない要素・タイムゾーン） |
| [`characters/`](characters/README.md) | キャラクター（名前・性格・話し方・関係性・設定・口調の例文） |
| [`lifestyles/`](lifestyles/README.md) | 生活様式（平日・休日の生活リズムと、起こりやすい出来事の種類。不在期間のシミュレーションで使う） |
| [`packages/`](packages/README.md) | 世界観・キャラクター・生活様式の組み合わせ。フロントが選ぶ単位 |

## 追加・変更の手順

- 世界観やキャラクター、生活様式を追加する場合は、該当フォルダに JSON を1つ追加し、`packages/` に組み合わせの JSON を追加する。テンプレートやコードの変更は不要。
- ファイル名は `<key>.json`（パッケージは `<id>.json`）とし、`key` / `id` にはファイル名と同じ値を入れる。使える文字は英小文字・数字・ハイフンのみ（`^[a-z0-9-]+$`）。
- 反映にはデプロイが必要（`npm run build` がこのフォルダを `dist/content/` にコピーし、Lambda に同梱される）。

## 注意

- `characterId` は「ユーザー×パッケージ」で一意。別のパッケージに切り替えるときは、フロントが新しい `characterId` を発番する（重要記憶・感情状態・会話ログはすべて `characterId` 単位で保存されるため）。
