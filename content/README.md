# content

キャラクターと世界観のデータファイル。プロンプトテンプレートからキャラクター固有・世界観固有の文面を切り離すために置いている。

フロントは `packageId` を選んで各エンドポイントに渡すだけで、サーバー（`src/lib/packages.ts`）がここから世界観とキャラクターを読み込み、プロンプトに差し込む。

| フォルダ | 内容 |
|---|---|
| [`worlds/`](worlds/README.md) | 世界観（舞台の説明・ルール・生成してはいけない要素） |
| [`characters/`](characters/README.md) | キャラクター（名前・性格・話し方・関係性・設定・口調の例文） |
| [`packages/`](packages/README.md) | 世界観とキャラクターの組み合わせ。フロントが選ぶ単位 |

## 追加・変更の手順

- 世界観やキャラクターを追加する場合は、該当フォルダに JSON を1つ追加し、`packages/` に組み合わせの JSON を追加する。テンプレートやコードの変更は不要。
- ファイル名は `<key>.json`（パッケージは `<id>.json`）とし、`key` / `id` にはファイル名と同じ値を入れる。使える文字は英小文字・数字・ハイフンのみ（`^[a-z0-9-]+$`）。
- 反映にはデプロイが必要（`npm run build` がこのフォルダを `dist/content/` にコピーし、Lambda に同梱される）。

## 注意

- `characterId` は「ユーザー×パッケージ」で一意。別のパッケージに切り替えるときは、フロントが新しい `characterId` を発番する（重要記憶・感情状態・会話ログはすべて `characterId` 単位で保存されるため）。
