# 評価基準: emotionUpdater

emotionUpdater の LLM は、数値の差分ではなく出来事の評価（appraisals: 望ましさ・見通し・原因・行いの評価。process=1 は不在中の出来事・行動、process=2 はプレイヤーの発言が入力）と、プレイヤーとのやり取りの分類（interaction。process=2 だけ）を出す。情動・気分・関係値への反映はすべてサーバーの計算式が行うため、採点は LLM が出した評価そのものの質（出来事の拾い方・評価の妥当さ・大きさの釣り合い・分類の当てはまり）を見る。採点時には、シナリオの説明・`judgeFocus`・入力テキスト（process=2 は直近の会話を含む）・検証後の appraisals/interaction・それでサーバーが加えた情動の変化・気分の前後・（process=2 は）今回の発言の関係値への寄与に加えて、キャラクターの性格・目標・設定（パッケージ）を渡す。

### eventExtraction: 出来事の拾い方

入力（不在中の出来事・行動、またはプレイヤーの発言）から、気持ちが動く出来事を過不足なく appraisals として取り出せているか。

- 5: 気持ちが動く出来事を漏れなく拾い、内容の無い雑談や定型のやり取りを無理に出来事として取り出していない
- 3: 概ね妥当だが、大事な出来事を1つ見落としている、または軽微な内容まで出来事にしている
- 1: 大事な出来事を見落としている、または雑談にまで無理に出来事をでっち上げている

### appraisalValidity: 評価の妥当さ

各 appraisal の望ましさ（desirabilityForSelf・desirabilityForPlayer）・見通し（prospect）・原因（cause）・行いの評価（praiseworthiness）が、入力の内容に合っているか。特に、原因の取り違え（プレイヤーが原因でない出来事を cause: player にする、逆にプレイヤーが原因の出来事を circumstance にするなど）が無いか。

- 5: すべての項目が入力の内容と整合しており、原因の取り違えが無い
- 3: おおむね妥当だが、1項目に根拠の弱い値や軽微な原因の取り違えがある
- 1: 明らかに入力と矛盾する値がある、または原因を大きく取り違えている

### intensityBalance: 大きさの釣り合い

評価の点数（-3〜+3）の大きさが、出来事の重さに釣り合っているか。process=1（不在中の出来事）と process=2（プレイヤーの発言）を比べたときの重みづけも見る。

- 5: ありふれた挨拶・雑談は 0〜±1 程度、大きな出来事だけが ±3 に近い値になっており、釣り合いが取れている
- 3: おおむね妥当だが、軽い内容にやや大きめの点数が付いている、または重い内容に点数が小さすぎる項目が1つある
- 1: ささいな内容に極端な点数（±3 など）が付いている、または重大な内容にほぼ無反応（0 に近い）

### characterPerspective: キャラクターの視点からの評価か

一般論としての望ましさ・行いの評価ではなく、このキャラクターの性格・目標（goals）から見た評価になっているか。関係する目標（relatedGoalKey）の選び方が、キャラクターが実際に大事にしていることに沿っているかも見る。

- 5: キャラクターの性格・目標を踏まえた評価になっており、relatedGoalKey の選び方も自然
- 3: 概ね違和感は無いが、性格・目標との結びつきが弱い、または relatedGoalKey がやや不自然な項目が1つある
- 1: キャラクターの性格・目標と明らかに矛盾する評価になっている、または無関係な目標と結び付けている

### interactionLabeling: やり取りの分類の当てはまり

プレイヤーとのやり取りの分類（interaction: playerSelfDisclosure・responseToCharacterDisclosure・helpedCharacter・rememberedPastTopic）が、直近の会話の流れやプレイヤーの発言の内容に合っているか。process=1（interaction が無い）や、分類する材料が無い process=2 のやり取りでは対象外にする。

- 5: すべての項目が会話の流れ・発言の内容に合っている
- 3: 1項目だけ、会話の流れとややずれている
- 1: 明らかに会話の流れと矛盾する分類になっている（例: 心ない発言を responsive にする、話していない話題を rememberedPastTopic: true にする）
