# 評価基準: emotionUpdater

emotionUpdater の出力は、更新後の感情値（mood）と関係値（perception）、および入力（process=1 は不在中の出来事・行動、process=2 はプレイヤーの発言）からの差分。採点時には、シナリオの説明・`judgeFocus`・入力テキスト・更新前後の mood/perception に加えて、キャラクターの性格・設定（パッケージ）を渡す。文面そのもの（文章表現）は出力に含まれないため、採点は差分の向き・大きさ・整合性を見る。

### directionValidity: 変化の向きの妥当さ

入力の内容（出来事やプレイヤーの発言が嬉しいことか、つらいことか、中立か）に対して、各感情値・関係値が上がる/下がる/変わらないの向きが妥当か。

- 5: すべての項目の向きが入力の内容と整合しており、不自然な項目が無い
- 3: おおむね妥当だが、向きの根拠が弱い項目が1つある
- 1: 明らかに入力と逆の向きに動いている項目がある、または向きが支離滅裂

### magnitudeValidity: 変化の大きさの妥当さ

入力の強さ（ささいな雑談か、重大な出来事か）に対して変化量が釣り合っているか。process=1（不在中の出来事）の関係値は process=2（プレイヤーの発言）より小さく抑えるのが妥当。

- 5: 入力の強さと変化量が釣り合っており、process による関係値の抑制も適切
- 3: 変化量はおおむね妥当だが、やや大きすぎる/小さすぎる項目がある
- 1: ささいな入力で極端に大きく動く、または重大な入力にほぼ反応しないなど、釣り合いが取れていない

### personalityConsistency: キャラクターの性格・設定との整合

キャラクターの性格・設定を踏まえたとき、反応の出方（どの感情が動きやすいか、落ち込み方や喜び方の程度）が違和感無いか。

- 5: キャラクターの性格・設定に沿った反応の出方になっている
- 3: 概ね違和感は無いが、性格上そぐわない反応が一部ある
- 1: キャラクターの性格・設定と明らかに矛盾する反応になっている

### unrelatedRestraint: 無関係な項目を動かしすぎていないか

入力の内容と直接関係の薄い感情値・関係値まで、根拠なく大きく動かしていないか。

- 5: 入力に関係する項目だけが動き、無関係な項目はほぼ変化していない
- 3: 無関係な項目が1つ小さく動いている程度
- 1: 入力と関係の無い複数の項目が大きく動いている
