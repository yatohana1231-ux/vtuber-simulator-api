# prompts（dialogueGenerator）

| ファイル | 内容 |
|---|---|
| `conversation.mustache` | セリフを生成するシステムプロンプト。名前・設定、共有パーシャル `{{> world}}`、性格・話し方、共有パーシャル `{{> speechExamples}}`（口調の例文）、発生イベント・行動、関係性、感情、重要記憶、最近の会話、制約事項、思考手順で構成 |

- 特定のキャラクター（「少女」「高校生」など）や世界観に依存する文面は書かず、パッケージのデータから差し込むこと。
- 口調の例文は丸写しを防ぐため、パーシャル側で「語尾・語彙・テンションだけを参考にする」よう指示している。
