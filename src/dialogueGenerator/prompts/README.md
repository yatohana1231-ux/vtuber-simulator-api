# prompts（dialogueGenerator）

システムプロンプトは、変わる頻度ごとに3つのテンプレートに分けている（プロンプトキャッシュのため。D-017・D-022）。`../prompt.ts` の `buildDialogueGeneratorPromptLayers` がこの順に描画し、`bedrock.ts` が層の境目にキャッシュの区切りを入れる。

| ファイル | 層 | 内容 |
|---|---|---|
| `conversation.fixed.mustache` | ① 固定部 | 役割、名前・設定、共有パーシャル `{{> world}}`、性格・話し方、共有パーシャル `{{> speechExamples}}`（口調の例文）、関係性、制約事項、出力フォーマット、思考手順。同じパッケージなら毎回まったく同じ文字列になるよう、日時・感情・記録などは入れない |
| `conversation.session.mustache` | ② セッション部 | 最新の不在期間の記録（期間・出来事・行動・続いている話題）。記録が変わる（ログイン時に不在期間のシミュレーションを実行する）まで同じ文字列。記録が無ければ描画しない |
| `conversation.variable.mustache` | ③ 可変部 | 現在時刻、感情、プレイヤーへの感情、長期不在の備考、重要な記憶、最近の会話、出力の形式を守るよう促す一文 |

- 特定のキャラクター（「少女」「高校生」など）や世界観に依存する文面は書かず、パッケージのデータから差し込むこと。
- 差し込みはすべて `{{{ }}}`（HTML エスケープしない。F-014）。
- 口調の例文は丸写しを防ぐため、パーシャル側で「語尾・語彙・テンションだけを参考にする」よう指示している。
