# prompts（dialogueGenerator）

システムプロンプトは、変わる頻度ごとに3つのテンプレートに分けている（プロンプトキャッシュのため。D-017・D-022）。`../prompt.ts` の `buildDialogueGeneratorPromptLayers` がこの順に描画し、`bedrock.ts` が層の境目にキャッシュの区切りを入れる。

| ファイル | 層 | 内容 |
|---|---|---|
| `conversation.fixed.mustache` | ① 固定部 | 役割、名前・設定、共有パーシャル `{{> world}}`、性格・段階によらない話し方、関係性（段階によらない前提）、制約事項（【これまでの関係】の数字を読み上げない・段階の変化を告げない、を含む）、出力フォーマット、思考手順。同じパッケージなら毎回まったく同じ文字列になるよう、日時・感情・記録・関係の段階などは入れない |
| `conversation.session.mustache` | ② セッション部 | `【今の関係】`（今の関係の段階の説明・話し方）と、共有パーシャル `{{> speechExamples}}`（段階の口調の例文。無ければキャラクター共通の例文）、続けて最新の不在期間の記録（期間・出来事・行動・続いている話題。記録があるときだけ）。段階と記録が変わるまで同じ文字列（D-033） |
| `conversation.variable.mustache` | ③ 可変部 | 現在時刻、感情、プレイヤーへの感情、`【これまでの関係】`（関係の履歴。D-033）、長期不在の備考、重要な記憶、最近の会話、出力の形式を守るよう促す一文 |

- 特定のキャラクター（「少女」「高校生」など）や世界観に依存する文面は書かず、パッケージのデータから差し込むこと。
- 差し込みはすべて `{{{ }}}`（HTML エスケープしない。F-014）。
- 口調の例文は丸写しを防ぐため、パーシャル側で「語尾・語彙・テンションだけを参考にする」よう指示している。
