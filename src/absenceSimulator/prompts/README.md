# prompts（absenceSimulator）

システムプロンプトは、プロンプトキャッシュのため固定部と可変部の2つのテンプレートに分けている（D-017・D-020）。`../prompt.ts` の `buildAbsenceSimulatorPromptLayers` がこの順に描画する。セッション部（②）は無い。

| ファイル | 層 | 内容 |
|---|---|---|
| `absenceSimulator.fixed.mustache` | ① 固定部 | 役割、キャラクター情報（名前・性格・設定）、共有パーシャル `{{> world}}`、書き方のルール（出来事・行動・続いている話題・全体）、JSON 出力形式。同じパッケージなら毎回まったく同じ文字列（日時・件数を入れない） |
| `absenceSimulator.variable.mustache` | ③ 可変部 | 不在期間、不在に入ったときの気分（新しい形の状態レコードがあるときだけ。気分・強い情動・欲求の文章。D-040）、行動の枠、出来事の種類（順番・件数）、続いている話題、最近の出来事（繰り返さない）、重要な記憶、ルールと出力形式を守るよう促す一文 |

- 書き方のルールは、2026-09-19 に stg のモデル（Nova Lite）で試した結果をもとに調整した（`.notes/done/absence-simulation-roadmap.md` の「状態」）。
- 特定の世界観・キャラクターに依存する文面は書かない（生活リズムや出来事の種類の説明は `content/lifestyles/` に書く）。差し込みはすべて `{{{ }}}`（HTML エスケープしない）。
