# prompts（emotionUpdater）

システムプロンプトは、プロンプトキャッシュのため固定部と可変部の2つのテンプレートに分けている（D-017・D-022）。`../prompt.ts` がこの順に描画する。

| ファイル | 層 | 内容 |
|---|---|---|
| `emotionUpdater.fixed.mustache` | ① 固定部 | 役割、キャラクター情報（名前・性格・設定）、共有パーシャル `{{> world}}`、process によらない更新ルール、JSON 出力形式。同じパッケージなら process によらず毎回まったく同じ文字列 |
| `emotionUpdater.variable.mustache` | ③ 可変部 | 現在の感情値・関係値、更新のインプット、process ごとの関係値の変化の目安（追加の更新ルール）、出力の形式を守るよう促す一文 |

- 特定の世界観・キャラクターに依存する文面は書かない。差し込みはすべて `{{{ }}}`（HTML エスケープしない。F-014）。
