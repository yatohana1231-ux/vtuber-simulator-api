# prompts（memoryRetriever）

システムプロンプトは、プロンプトキャッシュのため固定部と可変部の2つのテンプレートに分けている（D-017・D-022）。`../prompt.ts` がこの順に描画する。

| ファイル | 層 | 内容 |
|---|---|---|
| `memoryRetriever.fixed.mustache` | ① 固定部 | 役割・目的、キャラクター情報（名前・性格・設定）、共有パーシャル `{{> world}}`、保存する/しない基準、重要な制約、既存記憶との整合性ラベル、`memoryType`、JSON 出力形式。同じパッケージなら毎回まったく同じ文字列 |
| `memoryRetriever.variable.mustache` | ③ 可変部 | 既存の重要記憶、判定対象の出来事、出力の形式を守るよう促す一文 |

- 特定の世界観・キャラクターに依存する文面は書かない。差し込みはすべて `{{{ }}}`（HTML エスケープしない。F-014）。
